# Security Policy

Do not commit API keys, platform credentials, private customer assets, unpublished product data, or personally identifying media.

If you discover a vulnerability that could expose credentials, private media, or customer information, do not open a public issue. Contact the repository owner through the security-reporting channel shown on the GitHub profile and include a minimal reproduction without real customer data.

This repository contains workflow instructions and local validators. Security, billing, retention, and data-processing behavior of external generation or ASR providers remain the responsibility of the operator.
