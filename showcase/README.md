# Showcase Media Notice / 案例素材说明

This directory contains authorized historical test outputs that demonstrate the workflow:

```text
product image → 2×2 state sheet → continuous 15-second video
```

The three cases were selected to show different evidence routes:

- `shoe/`: unboxing, product presentation, visible-detail proof, and on-foot result;
- `wearable-device/`: worn state plus a restrained effect proxy without inventing an unknown control action;
- `cardigan/`: visible garment details followed by an actual worn result in a lived-in setting.

The files are direct historical outputs and intentionally retain visible limitations. They are workflow examples, not official material from CapCut, Xiaohongshu, TikTok, or any generation provider; they do not imply endorsement, affiliation, or guaranteed reproducibility.

The animated GIFs are silent README previews. Click a preview in the root README to play the corresponding full MP4 with sound and browser controls.
